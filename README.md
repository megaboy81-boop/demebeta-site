# DEMEBETA — Living Archive

성수 인디 스트릿웨어 캡 브랜드 DEMEBETA의 Living Archive 사이트.

## Stack
- Astro 6.3 + Tailwind 4 + TypeScript

## Dev
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Sections
- Lookbook / Seasons / Records / Beta / Materials / About / Stockists / Contact

## Deploy
GitHub Pages 자동 배포 (push to `main` → Actions → Pages).
배포 URL: https://megaboy81-boop.github.io/demebeta-site/
