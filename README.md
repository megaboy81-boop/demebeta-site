# DEMEBETA — Living Archive

성수 기반 디자이너 캡 브랜드 DEMEBETA의 GitHub Pages 사이트.

## Stack
- Astro 6.3
- Tailwind 4
- TypeScript

## Dev
```
npm install
npm run dev
```

## Asset Sync
기본 이미지 소스는 `/Users/megaboy/Desktop/드메베타`입니다.

```
npm run sync:assets
```

## Build
```
npm run build
```

## Sections
- Home
- Caps
- Lookbook
- Seasons
- Records
- Materials
- Beta
- About / Stockists / Contact

## Deploy
GitHub Pages 자동 배포 (push to `main` → Actions → Pages).
배포 URL: https://megaboy81-boop.github.io/demebeta-site/
